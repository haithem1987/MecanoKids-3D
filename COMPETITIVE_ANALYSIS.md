## 2. Analyse détaillée des acteurs clés

### Duolingo — Référence UX gamification
**Ce qui fonctionne** : streak quotidien = rétention imbattable (500 M utilisateurs, rétention J+7 ~60 %). Leaderboards hebdomadaires, notifications calibrées. Progression visible et récompenses fréquentes (XP, ligues). Onboarding en 30 secondes sans compte.
**Faiblesses** : contenu trop superficiel pour acquérir une vraie compétence. Le modèle freemium est agressif (publicités fréquentes, "cœurs" épuisables qui bloquent la progression).
**Leçon** : le streak et le feedback immédiat (son + animation + XP) sont les deux mécaniques de rétention les plus copiées. L'onboarding sans compte est décisif pour le B2C.

### Khan Academy Kids — Le standard de référence gratuit
**Ce qui fonctionne** : qualité pédagogique irréprochable, 0 publicité, 0 données enfants, totalement gratuit. Voix et personnages attachants pour les 2-8 ans. Confiance parentale maximale.
**Faiblesses** : pas de modèle économique (dépend des dons de Bill Gates / fondations). Pas de mécanique de jeu profonde. Interface datée côté enfant.
**Leçon** : le positionnement "0 pub, 0 données enfants" est un argument de confiance parentale très fort, pas juste une contrainte réglementaire. À mettre en avant dès la vitrine.

### Prodigy Math — Le piège du pay-to-win
**Ce qui fonctionne** : 50 M inscrits, adopté massivement par les enseignants américains, tableau de bord enseignant puissant.
**Faiblesses** : modèle controversé — les enfants non-payants perdent des batailles contre les payants. Parents et enseignants s'en plaignent ouvertement. NPS enseignant en chute. Abandonné par plusieurs districts scolaires.
**Leçon critique** : ne jamais pénaliser l'expérience de jeu de l'enfant en fonction du statut payant/gratuit. La limite gratuite chez nous (20 véhicules) est une restriction de contenu, pas une dégradation du jeu — cette distinction est fondamentale.

### CodeSpark Academy — Le concurrent direct sur le segment 5-8 ans non-lecteurs
**Ce qui fonctionne** : interface entièrement sans texte (Foos™), accessible aux 5-6 ans. Bonne rétention, utilisé dans 30 000 écoles américaines.
**Faiblesses** : code uniquement. Interface vieillissante. Peu présent en Europe et absent en arabe.
**Leçon** : l'angle "sans texte pour les 5-7 ans" est un vrai avantage concurrentiel. Nos miniatures visuelles et la synthèse vocale répondent exactement à ce besoin.

### Tinybop — Le plus proche de notre angle mécanique
**Ce qui fonctionne** : apps "The Human Body", "Simple Machines", "Robots" — précisément l'angle mécanique/ingénierie. Design soigné, pas de pub. Simple Machines est le concurrent le plus direct.
**Faiblesses** : apps isolées (pas de progression entre elles), pas de mode jeu profond, pas de catalogue abonné, pas de profil parent. Abandonné sur mobile (dernier update 2022, estimé).
**Taille** : très petit, < 1 M téléchargements total (estimé SensorTower). N'a jamais réussi à monétiser durablement.
**Leçon** : l'angle mécanique/ingénierie est validé (Tinybop l'a prouvé) mais la monétisation par app isolée ne tient pas. Le modèle catalogue abonné est la bonne réponse.

### Toca Boca — Maître du modèle premium enfants
**Ce qui fonctionne** : apps à 5-8 € achetées une fois, sans publicité, sans abonnement — confiance parentale maximale. Toca Life World a pivoté vers un modèle monde ouvert avec contenu IAP. Acquis par Spin Master pour ~700 M $.
**Faiblesses** : pas de valeur éducative revendiquée, pas de B2B écoles.
**Leçon** : les parents acceptent de payer pour une expérience propre. Le segment "premium sans pub" est solide, mais le catalogue abonné génère plus de LTV.

## 3. Opportunités identifiées

### 3.1 L'angle mécanique/ingénierie est réellement libre
Aucun acteur majeur ne couvre **l'ingénierie mécanique comme jeu profond** pour 5-12 ans :
- Tinybop : superficiel, abandonné
- Lego apps : companion apps, pas standalone
- GoldieBlox : jouet physique
- Crazy Machines 3 : puzzle PC adulte

**C'est la fenêtre.** Le parent qui cherche "jeu éducatif mécanique enfant" ne trouve rien de sérieux.

### 3.2 L'arabe est un marché sans concurrent
Aucun des acteurs listés n'a d'offre arabe sérieuse (support RTL, voix arabes, contenu adapté). 400 M de locuteurs arabes, forte aspiration éducative STEM dans les pays du Golfe et d'Afrique du Nord. Khan Academy a quelques traductions mais pas d'expérience native.

### 3.3 Le B2B écoles françaises est sous-servi
Chorus Pro (obligatoire pour les établissements publics français) est ignoré par tous les acteurs US. Les quelques acteurs français (Lumni, LaClasse.fr) ne font pas de jeux 3D. C'est une barrière à l'entrée pour les concurrents US, pas pour nous.

### 3.4 Le offline-first est rare
Khan Academy Kids et Scratch nécessitent une connexion pour certaines fonctionnalités. Dans les écoles avec mauvaise connexion (rural, pays en développement, salles sans Wi-Fi), le offline-first est un argument fort.

## 4. Recommandations concrètes pour notre pricing et positionnement

### Pricing
| Recommandation | Justification |
|:---|:---|
| **12,99 € / an famille (achat unique)** | Médiane du marché (60-80 $/an), aligné sur DragonBox/Tinybop mais catalogue |
| **Ne pas faire de mensuel au lancement** | Complexifie la comptabilité, attire les churners. Ajouter plus tard si demandé. |
| **Écoles : 3-5 € / élève / an** | Standard marché US (2-4 $), majorer légèrement pour couvrir Chorus Pro + support |
| **Pas de "freemium agressif"** | Leçon Prodigy : ne jamais dégrader l'expérience de jeu, seulement restreindre le contenu |
| **Prix unique = tous les jeux futurs** | C'est l'argument de vente face aux apps isolées à 5 € chacune |

### Positionnement
- **Versus Prodigy** : "Nous ne pénalisons pas l'enfant si les parents ne paient pas"
- **Versus Tinybop** : "Pas juste une app — un catalogue progressif avec profil et suivi"
- **Versus CodeSpark** : "L'ingénierie mécanique, pas juste le code"
- **Argument parent #1** : "0 publicité, 0 données enfant, 100 % hors-ligne" (Khan Academy Kids a prouvé que c'est décisif)
- **Argument parent #2** : "Compétences STEM mesurables avec bulletin imprimable" (unique sur le marché)

## 5. Leçons UX directement applicables

### UX-1 : Onboarding sans compte obligatoire
Duolingo, Scratch, Khan Academy Kids : on joue en 30 secondes sans créer de compte. Le compte est optionnel ou différé. **Notre bouton "Essayer gratuitement (sans compte)"** du Lot C1 est correct — ne jamais bloquer sur la création de compte avant la première partie.

### UX-2 : Feedback immédiat multi-sensoriel pour les 5-7 ans
CodeSpark et Duolingo : son + animation + XP à chaque bonne action. Les enfants non-lecteurs ont besoin de feedback **auditif + visuel simultané** (pas juste visuel). Notre synthèse vocale + sons de snapping sont essentiels, pas optionnels.

### UX-3 : Ne jamais montrer un écran vide ou un message d'erreur textuel à un enfant de 5 ans
Tinybop : quand une action est impossible, l'objet "résiste" physiquement. Scratch Jr : la pièce de code rebondit si elle ne s'emboîte pas. **Nos pièces refusées doivent avoir un retour physique (vibration, rebond), jamais un texte d'erreur.**

### UX-4 : La progression doit être visible sans lire
Prodigy, Duolingo : barres de progression, étoiles, badges visuels. Pour les 5-7 ans : les étoiles par véhicule dans notre catalogue remplissent ce rôle. S'assurer qu'elles sont visibles sans lire le nombre.

### UX-5 : Le streak est la mécanique de rétention #1
Duolingo a construit 40 M DAU principalement sur le streak. Notre mode "Défi du Jour" est le bon mécanisme — s'assurer que la notification (quand l'enfant ouvre l'app) rappelle le streak sans être anxiogène (Duolingo est critiqué pour ses notifications culpabilisantes).

## 6. Résumé exécutif

**La fenêtre existe.** Mécanique/ingénierie pour enfants est un angle non occupé par un acteur sérieux. Tinybop l'a prouvé valide mais a échoué faute de modèle économique durable. Notre catalogue abonné + B2B écoles + offline + arabe est une combinaison que personne n'a.

**Le risque principal n'est pas la concurrence — c'est la distribution.** Les acteurs qui ont réussi (Prodigy, CodeSpark) ont été adoptés par des enseignants qui les ont recommandés aux parents, pas par des parents qui les ont trouvés via Google. Le Lot C1 (vitrine) et les écoles pilotes (Étape 4) sont donc critiques.

**Prix : 12,99 € / an est défendable.** C'est moins cher qu'un app Osmo, moins cher qu'un mois de Prodigy, et ça couvre tous les jeux futurs.
